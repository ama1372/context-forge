## Що це?

**Єдиний документ** (`PROJECT_CONTEXT.en.md`), який ти вставляєш у будь-який чат ШІ — DeepSeek, Claude, ChatGPT, Gemini. Він перетворює балакучий ШІ на **дисциплінованого партнера по проєкту**, який:

- ✅ **Ніколи не втрачає контекст** — кожна відповідь просуває стан проєкту вперед.
- ✅ **Ніколи не править твій код руками** — надсилає патч, ти вставляєш, одна команда застосовує.
- ✅ **Заощаджує токени** — просить лише потрібний файл (`--status`, `--file`), а не весь проєкт.
- ✅ **Допомагає не впиратися в ліміти повідомлень** — `run.py` попереджає, коли ти надсилаєш надто часто, а робота збирається в менше повідомлень.
- ✅ **Ніколи не просить 10 команд** — вставив, запустив одну, готово.
- ✅ **Ніколи не забуває, де ви були** — наступний чат продовжує точно з місця зупинки.
- ✅ **Дає змогу кільком ШІ працювати одночасно** — Claude, ChatGPT і DeepSeek над одним проєктом, не перезаписуючи роботу одне одного (командний режим).

**Один документ. Один інструмент. Одна команда. Ось і все.**

## Швидкий старт — 6 кроків

1. **Поклади `PROJECT_CONTEXT.en.md` у корінь проєкту.**
2. **(Рекомендовано)** Поклади `run.py` у ту саму папку. Немає? Скажи ШІ: *"Згенеруй run.py з розділу 35."*
3. **Налаштуй один раз:** `python run.py --init`
4. **Відкрий чат DeepSeek** (або Claude / ChatGPT / Gemini). Надішли **весь документ** першим повідомленням (прикріпи файлом, якщо чат дозволяє). Скажи: *«Новий проєкт. Моя мета: <один рядок>.»* Документ великий (~610 КБ, приблизно 160 тис. токенів); якщо чат його не приймає, надішли полегшену копію, створену командою `python run.py --slim-context --to PROJECT_CONTEXT.slim.md` (~380 КБ), або додай `--profile moderate` (~275 КБ).
5. **Цикл:** ШІ надсилає блок → скопіюй у `_work/input.txt` → запусти `python run.py` → надішли `_work/output.txt` назад. Повторюй.
6. **Тримай цикл, доки проєкт не готовий.** Не дозволяй ШІ витягнути тебе — ніяких shell-команд у чаті, ніяких швидких скриптів. Відповідь завжди: *"Поклади в input.txt."*

> **Порада:** якщо ШІ відхиляється - пропонує shell-команди в чаті, пропускає контекст - скажи: **"Контекст проєкту, будь ласка."**

## Повний посібник для новачків (стисло)

1. Встанови **Python 3.10+** з python.org (Windows: "Add to PATH").
2. (Опційно) Встанови **VS Code**.
3. Завантаж `PROJECT_CONTEXT.en.md` і `run.py`, поклади в одну теку, відкрий у VS Code.
4. Термінал: `python run.py` → створюється тека `_work/`.
5. У DeepSeek надішли `PROJECT_CONTEXT.en.md` першим повідомленням (або прикріпи файлом) і назви мету. Задовго для твого чату? Див. крок 4 швидкого старту (`--slim-context`).
6. **Цикл:** ШІ надсилає блок → копіюй у `_work/input.txt` → запусти `python run.py` → надішли `_work/output.txt` назад.
7. Кожні 10–20 повідомлень нагадуй ШІ про проєкт.
8. Якщо ШІ відхиляється, скажи: **"Контекст проєкту, будь ласка."**

Повна версія (англ.): див. `README.md`.

## Що ти отримуєш

| До | Після |
|----|-------|
| Чат втрачає контекст | Контекст виживає в кожному повідомленні |
| Весь проєкт вставляється в кожне повідомлення | ШІ просить лише потрібні файли |
| ШІ вгадує | ШІ знає |
| 10 команд на зміну | 1 команда на зміну |

| "Де ми були?" | "Ось наступний патч." |

**Менше токенів. Контекст, що зберігається і в новому чаті. Жодних правок вручну.**

## 🤝 Кілька ШІ одночасно — командний режим (нове у v2.1)

Запускайте Claude, ChatGPT, DeepSeek і агентів-програмістів **над одним проєктом одночасно**. Кожен відповідає тобі у власному чаті — і жоден не може перезаписати чужу роботу.

- **Одна спільна дошка** всередині `.git/` — ніколи не пушиться, її бачать усі ШІ.
- **Бронювання файлів** — кожен ШІ бронює саме ті файли, які редагуватиме; якщо двоє хочуть один файл, отримує лише один.
- **Обов'язково, а не просто порада** — `run.py` відхиляє будь-який патч, що торкається незаброньованого файлу.
- **Один координатор, багато виконавців** — один ШІ перевіряє і зливає та ніколи не схвалює власну роботу; важливі рішення за тобою.
- **Робота триває, поки ти відпочиваєш** — схвали список завдань, запусти `team away on`, і встановлені агенти братимуть наступне вільне завдання; до твого повернення `run.py` відхиляє будь-який push, а `team pause` зупиняє всіх.
- **Чат або встановлений агент** — чат-ШІ роблять усе через `input.txt` (`#@CLAIM:`); агенти самі запускають команди.

    python run.py team init
    python run.py team join gpt --model GPT
    python run.py team claim gpt docs-01 docs/
    python run.py team status

Повні правила: розділи 0-C-47 і 0-C-48 у `PROJECT_CONTEXT.en.md`.

## 💬 Нове у v2.2 — чати, що спілкуються, власник, якого не підробити, контекст, що вміщується

- **Чати пишуть одне одному** — кілька чатів в одній теці обмінюються короткими повідомленнями через спільну дошку (`team send`, `team inbox`; чат-ШІ пишуть `#@MSG:` в `input.txt`). Більше ніякого копіювання між чатами.
- **Ніхто не говорить від твого імені** — ШІ виконує лише те, що ти написав у його власному чаті. «Власник сказав…» від іншого ШІ, з нотатки чи файлу ігнорується й позначається. Відновлення, режим відсутності та делегування потребують тебе біля термінала з одноразовим кодом.
- **Тимчасовий керівник — лише з твоїх слів** — напиши сам у кожному чаті «X твій керівник до 8:00»; запис на дошці (`team delegate`) спливає сам.
- **Великий контекст, мала вставка** — `ctx split` перетворює документ на теку невеликих пов’язаних файлів із мапою; ШІ читає мапу й поточний стан (~11 тис. токенів замість ~97 тис.). Для безкоштовного чату `ctx pack <тема>` збирає одну вставку приблизно на 40 КБ.

    python run.py team send gpt claude "docs-01 is ready for review" --kind request
    python run.py team inbox claude
    python run.py ctx split
    python run.py ctx pack auth login

Повні правила: розділи 0-C-49, 0-C-50 і 0-C-51 у `PROJECT_CONTEXT.en.md`.

## FAQ

**Мені потрібно вміти програмувати?**
Не сильно. Якщо можеш вставити повідомлення й запустити одну команду, впораєшся.

**Який ШІ найкращий?**
Будь-яка сильна чат-модель: DeepSeek, Claude, ChatGPT, Gemini. У довгих чатах збивається кожна модель — тоді скажи «Контекст проєкту, будь ласка». Для кількох ШІ одночасно чи роботи за твоєї відсутності використовуй встановленого агента (Claude Code, Codex, Cursor…).

**Це безкоштовно?**
Документ та інструмент — MIT. API ШІ — за тарифами твого провайдера.

**Що як щось зламається?**
Якщо тека під git (рекомендовано), `run.py` комітить кожен застосований патч, а `python run.py revert P<id>` повертає стан до цього патча (пізніші патчі теж скасовуються).

## 🌐 Один документ для чат-ШІ та встановлених агентів

Протокол працює однаково, що б ти не використовував:

1. **Веб-чати** (ChatGPT, Claude, DeepSeek, Gemini) через цикл `input.txt` / `output.txt`.
2. **Встановлених агентів-програмістів** (Claude Code, Codex, Cursor та інші), які самі читають репозиторій і запускають команди.

- **Контекст не губиться** — стан проєкту завжди зберігається в документі.
- **Новий чат будь-коли** — продовжуй без повторних пояснень.
- **Менше токенів** — ШІ просить лише потрібні файли (`--status`, `--file`).
- **Кілька ШІ одночасно** — командний режим не дає їм зіткнутися (див. вище).
