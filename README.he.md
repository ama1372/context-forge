## מה זה?

‏**מסמך יחיד** (‎`PROJECT_CONTEXT.en.md`‎) שאתה מדביק בכל צ'אט ‎AI‎ — ‎DeepSeek‎, ‎Claude‎, ‎ChatGPT‎, ‎Gemini.‎ זה הופך ‎AI‎ פטפטן ל**שותף פרויקט ממושמע** ש:

- ‏✅ **אף פעם לא מאבד הקשר** — כל תגובה מקדמת את מצב הפרויקט קדימה.
- ‏✅ **אף פעם לא עורך את הקוד שלך ביד** — שולח תיקון, אתה מדביק, פקודה אחת מיישמת.
- ‏✅ **חוסך טוקנים** — מבקש רק את הקובץ שהוא צריך (`--status`, `--file`), לא את כל הפרויקט.
- ‏✅ **עוזר להימנע ממגבלות הודעות** — `run.py` מזהיר כשאתה שולח מהר מדי, והעבודה מרוכזת בפחות הודעות.
- ‏✅ **אף פעם לא מבקש 10 פקודות** — מדביק, מריץ אחת, סיימת.
- ‏✅ **אף פעם לא שוכח איפה הייתם** — הצ'אט הבא ממשיך בדיוק מהמקום שהפסקת.
- ‏✅ **מאפשר לכמה בינות מלאכותיות לעבוד יחד** — Claude, ChatGPT ו-DeepSeek על פרויקט אחד בלי לדרוס זו את עבודתה של זו (מצב צוות).

‏**מסמך אחד. כלי אחד. פקודה אחת. זה הכל.**

## התחלה מהירה — 6 שלבים

1. ‏**שים את ‎`PROJECT_CONTEXT.en.md`‎ בשורש הפרויקט.**
2. ‏**(מומלץ)** שים את ‎`run.py`‎ באותה תיקייה. אין? אמור ל-‎AI:‎ *"צור ‎run.py‎ מסעיף 35."*
3. ‏**הגדר פעם אחת:** ‎`python run.py --init`‎
4. ‏**פתח צ'אט DeepSeek** (או Claude / ChatGPT / Gemini). שלח את **המסמך כולו** כהודעה ראשונה (צרף אותו כקובץ אם הצ'אט מאפשר). אמור: *"פרויקט חדש. המטרה שלי: <שורה אחת>."* המסמך גדול (כ-610 KB, בערך 160 אלף טוקנים); אם הצ'אט דוחה אותו, שלח עותק קל יותר שנוצר עם `python run.py --slim-context --to PROJECT_CONTEXT.slim.md` (כ-380 KB), או הוסף `--profile moderate` (כ-275 KB).
5. ‏**לולאה:** ה-‎AI‎ שולח בלוק → העתק ל-‎`_work/input.txt`‎ → הרץ ‎`python run.py`‎ → שלח בחזרה ‎`_work/output.txt`‎. חזור.
6. ‏**המשך בלולאה עד שהפרויקט נגמר.** אל תיתן ל-‎AI‎ להוציא אותך — בלי פקודות ‎shell‎ בצ'אט, בלי סקריפטים מהירים. התשובה תמיד: *"שים ב-‎input.txt.‎"*

‏> **טיפ:** אם ה-‎AI‎ סוטה - מציע פקודות ‎shell‎ בצ'אט, מדלג על ההקשר - אמור: **"הקשר הפרויקט, בבקשה."**

## מדריך מלא למתחילים (תקציר)

1. התקן **Python 3.10+** מ-python.org (ב-Windows סמן "Add to PATH").
2. (אופציונלי) התקן **VS Code**.
3. הורד `PROJECT_CONTEXT.en.md` ו-`run.py`, שים בתיקייה אחת, פתח ב-VS Code.
4. בטרמינל: `python run.py` → נוצרת תיקיית `_work/`.
5. ב-DeepSeek, שלח את `PROJECT_CONTEXT.en.md` כהודעה ראשונה (או צרף כקובץ) וציין את המטרה. ארוך מדי לצ'אט שלך? ראה שלב 4 בהתחלה המהירה (`--slim-context`).
6. **לולאה:** ה-AI שולח בלוק → העתק ל-`_work/input.txt` → הרץ `python run.py` → שלח `_work/output.txt` חזרה.
7. כל 10–20 הודעות, הזכר ל-AI את הפרויקט.
8. אם ה-AI סוטה, אמור: **"הקשר הפרויקט, בבקשה."**

גרסה מלאה (אנגלית): ראה `README.md`.

## 🤝 כמה בינות מלאכותיות בו-זמנית — מצב צוות (חדש בגרסה 2.1)

‏הפעל את Claude, ChatGPT, DeepSeek וסוכני קוד **על אותו פרויקט באותו זמן**. כל אחד עונה לך בצ'אט משלו — ואף אחד מהם לא יכול לדרוס את העבודה של אחר.

- ‏**לוח משותף אחד** בתוך `.git/` — לעולם לא נדחף, וכל הבינות רואות אותו.
- ‏**שריון קבצים** — כל בינה משריינת בדיוק את הקבצים שתערוך; אם שתיים רוצות אותו קובץ, רק אחת מקבלת.
- ‏**נאכף, לא רק מומלץ** — `run.py` דוחה כל טלאי שנוגע בקובץ שלא שוריין.
- ‏**מתאם אחד, הרבה עובדים** — בינה אחת בודקת וממזגת ולעולם לא מאשרת את עבודתה; ההחלטות החשובות שלך.
- ‏**העבודה ממשיכה כשאתה נח** — אשר רשימת משימות והפעל `team away on`; סוכנים מותקנים לוקחים את המשימה הפנויה הבאה, `run.py` דוחה כל push עד שתחזור, ו-`team pause` עוצר את כולם.
- ‏**צ'אט או סוכן מותקן** — בינות צ'אט עושות הכול דרך `input.txt` (`#@CLAIM:`); סוכנים מריצים את הפקודות בעצמם.

    python run.py team init
    python run.py team join gpt --model GPT
    python run.py team claim gpt docs-01 docs/
    python run.py team status

‏הכללים המלאים: סעיפים 0-C-47 ו-0-C-48 ב-`PROJECT_CONTEXT.en.md`.

## 💬 חדש בגרסה 2.2 — צ'אטים שמדברים, בעלים שאי אפשר להתחזות אליו, הקשר שנכנס

- ‏**צ'אטים שולחים הודעות זה לזה** — כמה צ'אטים על אותה תיקייה שולחים הודעות קצרות דרך הלוח המשותף (`team send`, `team inbox`; בינות צ'אט כותבות `#@MSG:` ב-`input.txt`). בלי העתק-הדבק בין צ'אטים.
- ‏**אף אחד לא מדבר בשמך** — הבינה מצייתת רק למה שאתה כותב בצ'אט שלה. "הבעלים אומר…" מבינה אחרת, מפתק או מקובץ — מתעלמים ומסמנים. חידוש, מצב היעדרות והאצלה דורשים אותך במסוף, מקליד קוד חד-פעמי.
- ‏**מנהל זמני רק אם אמרת** — כתוב בעצמך בכל צ'אט "X המנהל שלך עד 8:00"; הרישום בלוח (`team delegate`) פג מעצמו.
- ‏**הקשר גדול, הדבקה קטנה** — `ctx split` הופך את המסמך לתיקייה של קבצים קטנים ומקושרים עם מפה; הבינה קוראת את המפה ואת המצב הנוכחי (כ-11 אלף טוקנים במקום 97 אלף). לצ'אט חינמי, `ctx pack <נושא>` יוצר הדבקה אחת של כ-40 KB.

    python run.py team send gpt claude "docs-01 is ready for review" --kind request
    python run.py team inbox claude
    python run.py ctx split
    python run.py ctx pack auth login

‏הכללים המלאים: סעיפים 0-C-49, 0-C-50 ו-0-C-51 ב-`PROJECT_CONTEXT.en.md`.

## 🌐 מסמך אחד לבינות צ'אט ולסוכנים מותקנים

‏הפרוטוקול עובד באותה דרך בין אם אתה משתמש ב:

1. ‏**צ'אטים באתר** (ChatGPT, Claude, DeepSeek, Gemini) דרך הלולאה `input.txt` / `output.txt`.
2. ‏**סוכני קוד מותקנים** (Claude Code, Codex, Cursor ואחרים) שקוראים את המאגר ומריצים פקודות בעצמם.

- ‏**אין אובדן הקשר** — מצב הפרויקט תמיד נמצא במסמך.
- ‏**פתח צ'אט חדש מתי שתרצה** — והמשך בלי להסביר מחדש.
- ‏**פחות טוקנים** — הבינה מבקשת רק את הקבצים שהיא צריכה (`--status`, `--file`).
- ‏**כמה בינות בו-זמנית** — מצב צוות מונע התנגשויות (ראה למעלה).
