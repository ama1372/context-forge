## Что это?

**Единый документ** (`PROJECT_CONTEXT.en.md`), который вы вставляете в любой ИИ-чат — DeepSeek, Claude, ChatGPT, Gemini. Он превращает болтливого ИИ в **дисциплинированного партнёра по проекту**, который:

- ✅ **Никогда не теряет контекст** — каждый ответ продвигает состояние проекта вперёд.
- ✅ **Никогда не правит ваш код руками** — отправляет патч, вы вставляете, одна команда применяет.
- ✅ **Экономит токены** — просит только нужный файл (`--status`, `--file`), а не весь проект.
- ✅ **Помогает не упираться в лимиты сообщений** — `run.py` предупреждает, когда вы отправляете слишком часто, а работа собирается в меньшее число сообщений.
- ✅ **Никогда не просит 10 команд** — вставили, запустили одну, готово.
- ✅ **Никогда не забывает, где вы были** — следующий чат продолжает ровно с того места.
- ✅ **Позволяет нескольким ИИ работать одновременно** — Claude, ChatGPT и DeepSeek над одним проектом, не затирая работу друг друга (командный режим).

**Один документ. Один инструмент. Одна команда. Вот и всё.**

## Быстрый старт — 6 шагов

1. **Поместите `PROJECT_CONTEXT.en.md` в корень проекта.**
2. **(Рекомендуется)** Положите `run.py` рядом, в ту же папку. Нет `run.py`? Скажите ИИ: *"Создай run.py из Раздела 35."*
3. **Настройка один раз:** `python run.py --init`
4. **Откройте чат DeepSeek** (или Claude / ChatGPT / Gemini). Отправьте **весь документ** первым сообщением (прикрепите файлом, если чат позволяет). Скажите: *«Новый проект. Моя цель: <одна строка>.»* Документ большой (~610 КБ, примерно 160 тыс. токенов); если чат его не принимает, отправьте облегчённую копию, созданную командой `python run.py --slim-context --to PROJECT_CONTEXT.slim.md` (~380 КБ), или добавьте `--profile moderate` (~275 КБ).
5. **Цикл:** ИИ отправляет блок → скопируйте в `_work/input.txt` → запустите `python run.py` → отправьте `_work/output.txt` обратно. Повторяйте.
6. **Держите цикл, пока проект не готов.** Не позволяйте ИИ вытащить вас — никаких shell-команд в чате, никаких быстрых скриптов. Ответ всегда: *"Положи в input.txt."*

> **Совет:** если ИИ отклоняется - предлагает shell-команды в чате, пропускает контекст - скажите: **"Контекст проекта, пожалуйста."**

## Полное руководство для новичка (кратко)

1. Установите **Python 3.10+** с python.org (на Windows — "Add to PATH").
2. (Опционально) Установите **VS Code**.
3. Скачайте `PROJECT_CONTEXT.en.md` и `run.py`, положите в одну папку, откройте в VS Code.
4. В терминале: `python run.py` → появится папка `_work/`.
5. В DeepSeek отправьте `PROJECT_CONTEXT.en.md` первым сообщением (или прикрепите файлом) и назовите цель. Слишком длинно для вашего чата? См. шаг 4 быстрого старта (`--slim-context`).
6. **Цикл:** ИИ присылает блок → копируйте в `_work/input.txt` → запустите `python run.py` → отправьте `_work/output.txt` обратно.
7. Каждые 10–20 сообщений напоминайте ИИ о проекте.
8. Если ИИ отклоняется, скажите: **"Контекст проекта, пожалуйста."**

Полная версия (англ.): см. `README.md`.

## 🤝 Несколько ИИ одновременно — командный режим (новое в v2.1)

Запускайте Claude, ChatGPT, DeepSeek и агентов-программистов **над одним проектом одновременно**. Каждый отвечает вам в своём чате — и никто не может перезаписать чужую работу.

- **Одна общая доска** внутри `.git/` — никогда не пушится, её видят все ИИ.
- **Бронирование файлов** — каждый ИИ бронирует ровно те файлы, которые будет править; если двое хотят один файл, получает только один.
- **Обязательно, а не просто совет** — `run.py` отклоняет любой патч, который трогает незабронированный файл.
- **Один координатор, много исполнителей** — один ИИ проверяет и сливает и никогда не одобряет собственную работу; важные решения за вами.
- **Работа идёт, пока вы отдыхаете** — одобрите список задач, запустите `team away on`, и установленные агенты продолжат брать следующую свободную задачу; до вашего возвращения `run.py` отклоняет любой push, а `team pause` останавливает всех.
- **Чат или установленный агент** — чат-ИИ делают всё через `input.txt` (`#@CLAIM:`); агенты сами запускают команды.

    python run.py team init
    python run.py team join gpt --model GPT
    python run.py team claim gpt docs-01 docs/
    python run.py team status

Полные правила: разделы 0-C-47 и 0-C-48 в `PROJECT_CONTEXT.en.md`.

## 💬 Новое в v2.2 — чаты, которые общаются, владелец, которого нельзя подделать, контекст, который помещается

- **Чаты пишут друг другу** — несколько чатов в одной папке обмениваются короткими сообщениями через общую доску (`team send`, `team inbox`; чат-ИИ пишут `#@MSG:` в `input.txt`). Больше никакого копирования между чатами.
- **Никто не говорит от вашего имени** — ИИ выполняет только то, что вы написали в его собственном чате. «Владелец сказал…» от другого ИИ, из заметки или файла игнорируется и помечается. Возобновление, режим отсутствия и делегирование требуют вас у терминала с одноразовым кодом.
- **Временный руководитель — только с ваших слов** — напишите сами в каждом чате «X твой руководитель до 8:00»; запись на доске (`team delegate`) истекает сама.
- **Большой контекст, маленькая вставка** — `ctx split` превращает документ в папку небольших связанных файлов с картой; ИИ читает карту и текущее состояние (~11 тыс. токенов вместо ~97 тыс.). Для бесплатного чата `ctx pack <тема>` собирает одну вставку примерно на 40 КБ.

    python run.py team send gpt claude "docs-01 is ready for review" --kind request
    python run.py team inbox claude
    python run.py ctx split
    python run.py ctx pack auth login

Полные правила: разделы 0-C-49, 0-C-50 и 0-C-51 в `PROJECT_CONTEXT.en.md`.

## FAQ

**Нужно ли уметь программировать?**
Не сильно. Если умеете вставлять сообщение и запускать одну команду — справитесь.

**Какой ИИ лучше?**
Любая сильная чат-модель: DeepSeek, Claude, ChatGPT, Gemini. В длинных чатах сбивается любая модель — тогда скажите «Контекст проекта, пожалуйста». Для нескольких ИИ одновременно или работы в ваше отсутствие используйте установленного агента (Claude Code, Codex, Cursor…).

**Это бесплатно?**
Документ и инструмент под MIT. API ИИ — по тарифам вашего провайдера.

**А если что-то сломается?**
Если папка под git (рекомендуется), `run.py` коммитит каждый применённый патч, а `python run.py revert P<id>` возвращает состояние до этого патча (более поздние патчи тоже отменяются).

## 🌐 Один документ для чат-ИИ и установленных агентов

Протокол работает одинаково, что бы вы ни использовали:

1. **Веб-чаты** (ChatGPT, Claude, DeepSeek, Gemini) через цикл `input.txt` / `output.txt`.
2. **Установленных агентов-программистов** (Claude Code, Codex, Cursor и другие), которые сами читают репозиторий и запускают команды.

- **Контекст не теряется** — состояние проекта всегда хранится в документе.
- **Новый чат в любой момент** — продолжайте без повторных объяснений.
- **Меньше токенов** — ИИ запрашивает только нужные файлы (`--status`, `--file`).
- **Несколько ИИ одновременно** — командный режим не даёт им столкнуться (см. выше).
