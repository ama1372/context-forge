## 익숙한가요?

- 😤 **AI와 3시간 동안 코딩했어요. 채팅이 한계에 도달했어요. 모든 게 사라졌어요.**
- 🤯 **AI가 두 메시지 전에 결정한 것을 잊어버려요.**
- 💸 **매 새 메시지마다 프로젝트 전체를 붙여넣어요 — 토큰을 태우고, 시간을 낭비해요.**
- 🤖 **AI가 코드를 손으로 고치고, 뭔가를 부수고, 왜인지 모르겠어요.**
- 😴 **만드는 것보다 설명하는 데 더 많은 시간을 써요.**
- 🚫 **"메시지가 너무 많습니다, 나중에 다시 시도하세요"가 계속 나와요.**

**네?** 그럼 이건 당신을 위한 거예요.

---

## 이게 뭐예요?

**단일 문서** (`PROJECT_CONTEXT.md`)를 아무 AI 채팅에 붙여넣어요 — DeepSeek, Claude, ChatGPT, Gemini. 수다스러운 AI를 **규율 있는 프로젝트 파트너**로 바꿔줘요:

- ✅ **절대 컨텍스트를 잃지 않아요** — 모든 답변이 프로젝트 상태를 앞으로 나아가게 해요.
- ✅ **절대 코드를 손으로 고치지 않아요** — 패치를 보내고, 당신이 붙여넣고, 하나의 명령이 적용해요.
- ✅ **절대 토큰을 태우지 않아요** — 필요한 파일만 요청하고, 프로젝트 전체는 요청하지 않아요.
- ✅ **절대 계정을 차단하지 않아요** — 내장된 레이트 리밋 방지 프로토콜.
- ✅ **절대 10개의 명령을 요구하지 않아요** — 붙여넣고, 하나 실행하고, 끝.
- ✅ **어디에 있었는지 절대 잊지 않아요** — 다음 채팅은 정확히 그 지점에서 이어져요.

**하나의 문서. 하나의 도구. 하나의 명령. 그게 전부예요.**

## 작동 방식 (3단계)

### 1. 문서 받기
이 저장소에서 [`PROJECT_CONTEXT.en.md`](PROJECT_CONTEXT.en.md)를 다운로드하세요.

### 2. AI 채팅에 붙여넣기
DeepSeek(또는 Claude, ChatGPT, Gemini)로 새 채팅을 열어요. 문서 전체를 **첫 메시지**로 붙여넣어요. 무엇을 만들고 싶은지 한 줄 적어요.

### 3. AI를 따라가기
AI가 `run.py` (작은 Python 도구)를 줘요. 저장하세요. 그때부터:

> **붙여넣기 → `python run.py` 실행 → 출력을 다시 보내기.**

이게 전체 워크플로우예요. 영원히.

## 무엇을 얻게 되나요

| 이전 | 이후 |
|------|------|
| 채팅이 컨텍스트를 잃음 | 컨텍스트가 매 메시지에서 살아남음 |
| 답변당 5000 토큰 | 답변당 ~300 토큰 |
| AI가 추측 | AI가 앎 |
| 변경당 10개 명령 | 변경당 1개 명령 |
| 계정 차단 | 계정 안전 |
| "어디 있었지?" | "다음 패치입니다." |

**토큰 40–80% 절감. 컨텍스트 손실 제로. 수동 편집 제로.**

## 어떤 언어와도 작동

Rust, Python, Node, Go, C++, 뭐든지. 프로젝트를 어떻게 빌드하고 테스트할지 `run.py`에게 한 번만 알려주면 돼요 — 프로토콜은 모든 언어에서 동일해요.

---

## 문서 언어

규칙 문서는 **영어만** — 모든 AI가 동일하게 파싱하고 하나의 진실 원천이 있도록.

**하지만 AI와의 대화는 당신의 언어로.** 첫 메시지를 한국어, 페르시아어, 아랍어, 중국어로 쓰면 AI가 같은 언어로 답해요. 문서는 보편적이에요.

## FAQ

**코딩을 알아야 하나요?**
많이 필요 없어요. 메시지를 붙여넣고 명령 하나를 실행할 수 있으면 돼요.

**어떤 AI가 가장 좋아요?**
DeepSeek — 프로토콜을 가장 정확히 따라요. Claude, ChatGPT, Gemini도 작동해요.

**무료인가요?**
문서와 도구는 MIT. AI API는 제공자 요금.

**뭔가 깨지면요?**
모든 게 git으로 버전 관리돼요. 명령 하나로 되돌려요. 문서가 설명해요.
