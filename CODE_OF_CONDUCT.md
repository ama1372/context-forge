# Code of Conduct

## Our pledge

We want this project to be a welcoming space for everyone, regardless of experience, language, nationality, gender, identity, or background. This is a small project; we intend to keep it kind and easy to work in.

## Expected behavior

- Be respectful. Disagree with ideas, not people.
- Assume good faith. Ask before assuming malice.
- Keep criticism constructive and specific.
- Respect the project's scope and its rules (see `PROJECT_CONTEXT.en.md`).

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or imagery.
- Publishing others' private information without permission.
- Sustained disruption of discussions.

## Scope

This code applies to issues, pull requests, discussions, and any other project space.

## Enforcement

If you see or experience unacceptable behavior, open a private issue or contact the maintainer via GitHub. Reports will be reviewed and acted on promptly and fairly. Consequences may include a warning, temporary restriction, or permanent ban from the project spaces.

## Attribution

This Code of Conduct is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), simplified for a small project.
