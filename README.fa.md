# PROJECT_CONTEXT

یک سند واحد برای ساخت نرم‌افزار با هوش مصنوعی (DeepSeek، Claude، GPT، Gemini). هر پیام AI = یک پچ کد + یک پچ کانتکست. همه‌چیز از طریق `_work/input.txt` و `_work/output.txt` جریان دارد و با یک ابزار اعمال می‌شود: `run.py`.

## چه مشکلاتی را حل می‌کند

- **لیمیت چت.** کانتکست در هر پیام به‌روز می‌شود؛ چت جدید فقط با این سند + dump وضعیت ادامه می‌دهد.
- **توکن‌سوزی.** فلگ‌های `run.py` به AI اجازه می‌دهند فقط چیزی که لازم دارد را بخواهد — `--status` حدود ۳۰۰ بایت، `--file X` چند کیلوبایت.
- **جابجایی لنگر.** Fuzzy matching + بررسی hash، پچ‌ها را حتی بعد از ویرایش معتبر نگه می‌دارد.
- **مسدود شدن اکانت.** MSG-SEED + بسته‌بندی + فاصله‌ی زمانی اکانت را امن نگه می‌دارد.

## فایل‌ها

| فایل | نقش |
|------|-----|
| `PROJECT_CONTEXT.md` | قانون اساسی — قوانین، گردش کار، قالب‌ها |
| `run.py` | تنها ابزار — dump / apply / کامیت / تگ |
| `_work/` | پوشه‌ی ارتباط با AI |

## شروع سریع

    python run.py --init

سپس `PROJECT_CONTEXT.md` را در ریشه‌ی پروژه بگذار، یک چت با AI باز کن و سند را پیست کن.

AI یک پچ می‌نویسد. آن را در `_work/input.txt` بریز و بزن:

    python run.py

پیام بعدی AI از `_work/output.txt` ساخته می‌شود.
